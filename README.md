# تحدي الـ 30 ورقة - لعبة اسئلة الثانوية العامة

## 30-Card Challenge - Thanaweya Amma Question Game

### طريقة التشغيل / How to Run
1. افتح ملف `index.html` في أي متصفح حديث (Chrome, Firefox, Edge, Safari)
2. Open `index.html` in any modern browser

### المميزات / Features
- 300 سؤال منهجي متنوع / 300 curriculum questions
- مسارين: علمي علوم و علمي رياضة / Two tracks: Science & Math
- ترجمة كاملة عربي/انجليزي / Full Arabic/English toggle
- نظام افخاخ استراتيجي / Strategic trap system
- لعبة مصغرة تفاعلية / Interactive mini-game
- قائمة متصدرين / Leaderboard

### هيكل الملفات / File Structure
```
game/
├── index.html          # Main game page
├── css/
│   └── style.css       # Styling & RTL support
├── js/
│   ├── questions.js    # 300 questions database
│   └── game.js         # Game engine & logic
└── README.md
```

### المواد / Subjects
- احياء (علمي علوم فقط) / Biology (Science only)
- رياضيات (علمي رياضة فقط) / Math (Math only)
- كيمياء (مشترك) / Chemistry (both)
- فيزياء (مشترك) / Physics (both)
- نحو عربي (مشترك) / Arabic Nahw (both)
- انجليزي (مشترك) / English (both)
